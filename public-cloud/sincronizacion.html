Flujo académico

Cómo funciona

No hay conexión automática entre entornos.

1
Reserva pública

El navegador genera un UUID y guarda los datos mínimos.

2
Importación privada

Personal autorizado valida el JSON y gestiona el estado localmente.

3
Respuesta mínima

El entorno privado exporta UUID, estado, fecha, hora y fecha de actualización.

4
Consulta actualizada

El paciente importa la respuesta y consulta el UUID en este navegador.

Limitación importante

Una solución real requeriría API segura, base de datos, VPN, autenticación robusta, cifrado en tránsito, controles de acceso y monitoreo. Los archivos nunca deben incluir historias, diagnósticos o tratamientos.
