Intercambio manual

Validar, importar y responder

Solo se intercambia la información mínima necesaria para coordinar una cita.

1. Importar reserva pública

Se rechazan extensiones incorrectas, JSON inválido, UUID duplicado, fechas inválidas, campos inesperados y cualquier campo médico sensible.

2. Exportar respuesta mínima

La salida contiene únicamente UUID, estado, fecha, hora y fecha de actualización.

Separación obligatoria

Las historias clínicas, diagnósticos, tratamientos, documentos y observaciones nunca se exportan. Esto no es una integración automática ni un sistema de producción.
